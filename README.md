# Trading Strategies

A collection of Jupyter Notebook experiments comparing different algorithmic trading strategies using historical market data. The notebooks fetch daily stock prices with `yfinance`, implement and visualize each strategy with `matplotlib`, and calculate simulated trade revenue or profit.

> These notebooks are for educational and experimental purposes only. They do not account for all real-world trading costs, slippage, taxes, survivorship bias, or robust out-of-sample validation, and they are not financial advice.

## Strategies

| Notebook | Strategy | Summary |
|---|---|---|
| [MACrossover.ipynb](MACrossover.ipynb) | Moving-average crossover | Compares short- and long-term moving averages, searches a range of window lengths, and also explores a combination with RSI. |
| [MeanReversion.ipynb](MeanReversion.ipynb) | Mean reversion | Trades deviations from a rolling mean using rolling standard-deviation bands and searches for effective mean and sigma parameters. It uses Procter & Gamble (PG), rather than NVDA. |
| [StochasticOscillator.ipynb](StochasticOscillator.ipynb) | Stochastic oscillator | Calculates `%K` and `%D` and generates buy/sell signals from the oscillator and its signal line. |
| [RandomForest.ipynb](RandomForest.ipynb) | Random forest classifier | Uses technical features to train a classifier, estimates next-period direction probability, and converts predictions into trading signals. |
| [LGBM.ipynb](LGBM.ipynb) | LightGBM classifier | Trains a gradient-boosted decision-tree model on engineered market features and uses its predictions to trade NVDA. |
| [OGS1.ipynb](OGS1.ipynb) | Adaptive dual-risk strategy | Uses probabilistic buy/sell decisions controlled by `R_up` and `R_down`, updating the probabilities after each trade according to outcome. |

## Data

Most notebooks use one year of daily historical data for NVIDIA (NVDA). The mean-reversion notebook uses PG. Data is downloaded at runtime through Yahoo Finance, so an internet connection is required and the available data or formatting may change.

## Requirements

The notebooks use the following Python packages:

- `jupyter` or JupyterLab
- `yfinance`
- `pandas`
- `numpy`
- `matplotlib`
- `scikit-learn` (Random Forest and LightGBM notebooks)
- `lightgbm` (LightGBM notebook)

Install the common dependencies with:

```bash
pip install jupyter yfinance pandas numpy matplotlib scikit-learn lightgbm
```

## Usage

From this directory, start Jupyter:

```bash
jupyter notebook
```

Then open and run a notebook. The notebooks are set up to download market data and display charts inline. Re-run notebooks with fresh data to reproduce or compare results.

## Implementation Notes

- Buy and sell signals are generally applied to daily closing prices.
- Several strategies use a fixed trade volume or share count for revenue/profit calculations.
- Strategy parameters are often hard-coded or tuned over the historical period shown in the notebook.
- Charts and trade totals are embedded in the notebook outputs and may be regenerated by rerunning the cells.
- Test results and parameter searches may suffer from look-ahead or in-sample bias unless stricter validation is added.
